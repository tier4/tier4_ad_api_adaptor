# Migrate to Manual Control API

遠隔操作やジョイスティック操作のAPIは、ペダル以外の複数の制御方式を想定した仕様に変更されている。そのため、使用前に制御方式を選択するAPIを呼び出す必要がある。
制御方式の選択を行うまで関連するトピックが公開されない点に注意。
詳細は[Manual Control API](https://autowarefoundation.github.io/autoware-documentation/main/design/autoware-architecture-v1/interfaces/ad-api/features/manual-control/)を参照のこと。
